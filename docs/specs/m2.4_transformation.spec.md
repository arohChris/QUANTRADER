# Spec: M2.4 Transformation — Tick → Candle (multi-interval)

Purpose: Aggregate validated ticks into OHLC `Candle` contracts at the configured interval (stateful builder, pure calc).
Inputs: `md: MarketData` (kind=`tick`, payload=`Tick`, aware UTC timestamps) — from M2.3 validate pass.
Outputs: `Candle | None` — open bucket returns None (still forming); closed/final returns frozen `Candle`.
Edges:
- single tick in bucket → open, returns None; close → Candle with O=H=L=C=price, tick_count=1
- ticks same price → O=H=L=C=price; tick_count=N
- out-of-order tick within same open bucket → OHLC updated in place (no drop)
- tick with exchange_timestamp in prior closed bucket → Drop(reason=`invalid_timestamp`) — late reject
- tick exchange_timestamp in next/future bucket → starts new open bucket (prior returns closed Candle on boundary cross)
- interval boundary: tick at exact `interval_end` → closes prior, opens new
- empty input / no tick → returns None (no candle)
- gapped quality input → candle quality_status=`GAP_AFFECTED` (never CLEAR)
- non-tick kind or non-Tick payload → Drop(reason=`missing_field`)
- naive/None timestamps → Drop(reason=`invalid_timestamp`) — same as M2.3 input guarantee
- spread stats: both bid & ask present → average/min/max(ask-bid) over ticks in bucket (Decimal mid-calc, store float per Candle contract); either bid or ask is None on any contributing tick → average_spread=min_spread=max_spread=None (all-or-none)
Supported intervals: `1m, 5m, 15m, 40m, 1h, 2h, 4h, 24h` — floor(exchange_timestamp) to the interval boundary UTC (not just to the minute); unknown interval → `ValueError` at builder construction. `interval_end=interval_start+duration`; `expected_duration_ms` = duration in ms.
Correct: floor(exchange_timestamp) to interval boundary UTC (day-relative minutes // interval_minutes); interval_start=floor, interval_end=start+duration; OHLC from Tick.price only; spread stats from bid/ask when present (all-or-none per bucket); rounding HALF_UP to price precision (pass-through of already-normalized price — no re-round); tick_count exact integer count; aggregation_version=`agg_v2`.
Adversarial: price=0 or negative → Drop(reason=`negative_price`); future timestamp beyond received+5s → Drop(reason=`future_timestamp`) — defensive re-check same rule as M2.3 (M2.3 already drops; M2.4 re-checks for safety, not dead code); single candle with 10k ticks → tick_count=10000 exact; interval_start=Naive datetime → Drop.
State: one builder per `(instrument_id, broker, interval)`; pure sync `def on_tick(md) -> Candle | Drop | None`; `close() -> Candle | None` flushes open bucket. No clock dependency (bucket from md.exchange_timestamp only).
