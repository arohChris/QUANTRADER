# Spec: M2.4 Transformation — Tick → Candle (1m base)

Purpose: Aggregate validated 1m-bucketed ticks into OHLC `Candle` contracts (stateful builder, pure calc).
Inputs: `md: MarketData` (kind=`tick`, payload=`Tick`, aware UTC timestamps) — from M2.3 validate pass.
Outputs: `Candle | None` — open bucket returns None (still forming); closed/final returns frozen `Candle`.
Edges:
- single tick in bucket → open, returns None; close → Candle with O=H=L=C=price, tick_count=1
- ticks same price → O=H=L=C=price; tick_count=N
- out-of-order tick within same open bucket → OHLC updated in place (no drop)
- tick with exchange_timestamp in prior closed bucket → Drop(reason=`invalid_timestamp`) — late reject
- tick exchange_timestamp in next/future bucket → starts new open bucket (prior returns closed Candle on boundary cross)
- interval boundary: tick at exact `interval_end` → closes prior, opens new
- empty input / no tick → returns None (no candle)
- gapped quality input → candle quality_status=`GAP_AFFECTED` (never CLEAR)
- non-tick kind or non-Tick payload → Drop(reason=`missing_field`)
- naive/None timestamps → Drop(reason=`invalid_timestamp`) — same as M2.3 input guarantee
Correct: floor(exchange_timestamp) to minute UTC; interval_start=floor, interval_end=start+60s; OHLC from Tick.price only; spread stats from bid/ask when present; rounding HALF_UP to price precision (pass-through of already-normalized price — no re-round); tick_count exact integer count; aggregation_version=`agg_v2`.
Adversarial: price=0 or negative → Drop(reason=`negative_price`); future timestamp beyond received+5s → Drop(reason=`future_timestamp`); single candle with 10k ticks → tick_count=10000 exact; interval_start=Naive datetime → Drop.
State: one builder per `(instrument_id, broker, interval)`; pure sync `def on_tick(md) -> Candle | Drop | None`; `close() -> Candle | None` flushes open bucket. No clock dependency (bucket from md.exchange_timestamp only).
