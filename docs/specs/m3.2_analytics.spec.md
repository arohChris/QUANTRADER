## Contract (frozen by m3.1 §Contracts — conformance, not re-definition)

Each file exposes exactly:
- `NAME: str` — `"rsi_14"` / `"ema_20"` / `"tick_rate"` (matches capabilities.yaml key)
- `REQUIREMENTS: DataRequirement` (in-module frozen model; `extra="forbid"`)
- `compute(candles, params) -> float` — signature **exactly** `(candles, params)`; no
  provider / clock / `as_of` / timeframe parameter ever (Isolation Law — enforced at
  `registry.register`, `ValueError` if smuggled)
- No I/O, no clock, no RNG, no state between calls — sync pure, deterministic
- `candles: list[Candle]` — the engine-gated window of **one resolved timeframe**
  (§6a.2b: timeframe comes from the caller; a compute never selects bars itself)
- `params: dict[str, float]` — effective params after precedence
  (request overrides > asset profile > `REQUIREMENTS.defaults`); unknown keys are
  **ignored** (forward-compat); `params={}` must still work (defaults path)
- Return **full-precision `float`** — no rounding inside compute (m3.1: "engine does
  not round"); NaN sentinel is legal (engine omits feature + `invalid:<f>` warning)

## HUMAN LAW (carried from m3.1 — binding here)

> **Analytic Timeframe Isolation.** `compute(candles, params)` has no provider, no
> clock, no I/O — it cannot pull candles for another timeframe and never selects its
> own timeframe; the engine's wrong-series guard already guarantees series identity.

> **Research pins (m3.1 §Research pins REV5, adopted — no fork):**
> RSI/ATR smoothing = **Wilder α=1/n, first value = SMA of first n changes, recursive
> after** (bible pseudocode is Cutler-SMA → deviation D1/D4, resolved to Wilder);
> RSI zero branches three-way (REV5/A48): `avg_loss=0 ∧ avg_gain>0 → 100`,
> `avg_gain=0 ∧ avg_loss>0 → 0`, `avg_gain=0 ∧ avg_loss=0` (flat) → **50 as
> PROJECT canonical rule — mathematically neutral** (human ruling 2026-09-26 A48,
> supersedes the 2026-09-25 flat→100 rule; TV/TA-Lib state no 0/0 branch, never
> claimed as doc-verified);
> **no epsilon guards** (branch on zero, never `avg_loss or 1e-9` — deviation D2);
> EMA seed = **first source value** — pinned implementation decision locked by
> golden test (A48 canon: initialization explicitly pinned to the selected reference
> implementation and verified by golden tests; never assumed from the indicator name);
> RSI min-input = **15 closes** for period 14 (mathematical minimum:
> 14 changes need 15 closes; min-history derived from the math — library lookbacks
> verification-only, per m3.1 REV5).

> **§8b gates are the engine's** (`INSUFFICIENT` < `minimum_history`, `WARMUP_INCOMPLETE`
> < `minimum_history + warmup`); a compute never decides readiness — it only refuses
> honestly when its own math cannot produce a value (§Edges: NaN / `ValueError`).

## Per-analytic definitions

### `rsi_14` — Wilder RSI

- `REQUIREMENTS = DataRequirement(needs=("price",), minimum_history=15, warmup=0,
  defaults={"period": 14.0})` — `minimum_history=15` is the **pinned mathematical
  minimum** (14 changes need 15 closes; REV4 — never "TA-Lib lookback");
  `warmup=0` because the pin already *is* the first-valid-bar gate (any stabilization
  window beyond it = re-LGTM of m3.1 pins first). `dependencies=()`,
  `provides_regime=False`, `history_duration=None`.
- Params: `period` — must be an **integral** value ≥ 2 (§3.13 `rsi_period 2-100`;
  validated in compute, see Edges). Direct calls without the key fall back to 14
  (mirrors `REQUIREMENTS.defaults` so `compute(c, {})` works).
- Math (on `closes[i] = candle.close`, `n = len(closes)`, `p = period`):
  1. `n == 0` → `ValueError`. Any non-finite close → return `nan`.
  2. `n <= p` → return `nan` (no seed possible — engine's static min may be below a
     dynamic override period; NaN → engine `invalid:<f>`, never a partial number).
  3. changes `d_i = close_i - close_{i-1}` for `i = 1..n-1`; `gain = max(d, 0)`,
     `loss = max(-d, 0)`.
  4. **Seed:** `avg_gain = sum(gain_1..gain_p)/p`, `avg_loss = sum(loss_1..loss_p)/p`
     (SMA of the first `p` changes — Wilder).
  5. For `i = p+1..n-1`: `avg_gain = (avg_gain*(p-1) + gain_i)/p`,
     `avg_loss = (avg_loss*(p-1) + loss_i)/p` (Wilder recursive, α = 1/p).
  6. Branch (never epsilon, REV5/A48): `avg_gain == 0.0 and avg_loss == 0.0 → 50.0`
     (flat, `RS = 0/0` — neutral 50 checked FIRST); `avg_loss == 0.0 → 100.0`
     (gains only); `avg_gain == 0.0 → 0.0` (losses only); else
     `RSI = 100 - 100/(1 + RS)` with `RS = avg_gain/avg_loss`.
  7. Return the last RSI (current value), full precision.
- Output invariant: finite result ∈ `[0.0, 100.0]`.

### `ema_20` — Pine-seed EMA

- `REQUIREMENTS = DataRequirement(needs=("price",), minimum_history=20, warmup=5,
  defaults={"period": 20.0})` — `minimum_history = period` per §8b EMA exemplar
  (`EMA200: minimum 200`); `warmup=5` **scaled from that exemplar's ratio** (EMA200
  warmup 50 = 25% of period → EMA20 warmup 5; gates: <20 `INSUFFICIENT`,
  20–24 `WARMUP_INCOMPLETE`, ≥25 pristine). `dependencies=()`,
  `provides_regime=False`, `history_duration=None`.
- Params: `period` — integral value ≥ 1 (EMA(1) = last close is legal); fallback 20
  when key absent. Unknown keys ignored.
- Math: `α = 2/(p+1)`; **seed `EMA_0 = close_0`** (Pine `pine_ema` — first source
  value); `EMA_i = α·close_i + (1-α)·EMA_{i-1}`. Return the last EMA, full precision.
- Edges: `n == 0` → `ValueError`; non-finite close → `nan`; `n == 1` → seed
  (`close_0`) — EMA is always defined for `n ≥ 1` (no NaN branch).

### `tick_rate` — ticks-per-bar mean (proxy)

- `REQUIREMENTS = DataRequirement(needs=("tick_count",), minimum_history=1, warmup=0,
  defaults={})` — no params. PROXY_LIMITED semantics live in capabilities.yaml
  (`method: tick_count_proxy`, warning `tick_count ≠ volume`) + the engine's capability
  gate; this file only computes the number.
- Math: `mean(tick_count_i for each candle)` = `sum/n` (ticks per bar of the resolved
  timeframe; at `1m` this is ticks per minute). Return full-precision float.
- Edges: `n == 0` → `ValueError`; any non-finite `tick_count` → `nan`;
  all-zero tick counts → `0.0` (valid, not an error).

## Edges (one test each — §2 Step 3)

- RSI flat prices (all closes equal) → exactly `50.0` (pinned neutral, REV5/A48;
  `avg_gain==0 and avg_loss==0` branch checked FIRST).
- RSI all losses (`avg_gain==0`, `avg_loss>0`) → exactly `0.0`.
- RSI zero-loss with gains (`avg_loss==0`, `avg_gain>0`) → exactly `100.0`
  (branch, **not** epsilon — a 1e-17 float loss from additive noise is still `> 0`,
  so tests must use exactly-representable series; see §Test plan note).
- RSI `n == period` (14 closes @ p14) → `nan` (no seed); `n == period+1` (15) →
  finite — the pinned boundary.
- RSI dynamic override `period=100` on 15 bars → `nan` (engine emits
  `invalid:rsi_14`; never a number from a truncated series — §Open flag).
- RSI `period < 2` (`1.0`, `-5.0`, `0.0`) → `ValueError`.
- RSI/EMA non-integral period (`14.5`) or non-finite period (`inf`, `nan`) →
  `ValueError` (adversarial — params are caller-controlled).
- RSI/EMA/tick_rate `compute([], …)` → `ValueError`.
- RSI/EMA non-finite close (`nan` in series) → `nan` (never raises, never a number).
- `params=None` → `ValueError`; `params={}` → defaults path works.
- EMA single candle → seed `close_0`; EMA golden recursion exact (dyadic series).
- tick_rate `[8,4,12]` → exactly `8.0`; zero tick counts → `0.0`.
- Every file's `REQUIREMENTS` fields == the values pinned in this spec (frozen, `extra=forbid`).
- `AnalyticsRegistry.from_package()` discovers **exactly** `{rsi_14, ema_20, tick_rate}`
  (sorted-set equality — future P18 files will extend this test, it is the P17 batch lock).
- Engine end-to-end with **default registry + real `config/assets/forex.yaml`**:
  `features=("rsi_14","tick_rate")` on a 15-bar ascending series →
  `rsi_14 == 100.0` exactly (all gains → avg_loss 0), `tick_rate` present,
  `capability_status == PROXY_LIMITED` (real yaml: tick_rate is proxy), warning
  contains `tick_count ≠ volume`.

## Adversarial (must be in tests)

- `period=float("inf")` / `float("nan")` → `ValueError` (never `int(inf)` crash-class).
- `params={"period": -5.0}` → `ValueError` (hostile override fails loud, §3.13).
- `compute(candles, None)` → `ValueError`.
- Closes containing `float("inf")` → `nan`, not `inf` result.
- Hostile unknown param keys (`{"evil": 1.0}`) ignored, defaults still apply.
