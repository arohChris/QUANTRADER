## Contract (frozen by m3.1 §Contracts — same as P17)

`NAME: str` (== capabilities.yaml key) · `REQUIREMENTS: DataRequirement` (frozen,
`extra="forbid"`) · `compute(candles, params) -> float` exactly — Isolation Law
(no provider/clock/as_of/timeframe), sync pure, deterministic, no I/O/clock/RNG/state.
`params` pre-merged (overrides > profile > defaults), unknown keys ignored,
`params={}` must work (per-file fallback constant mirrors `REQUIREMENTS.defaults`).
Full-precision float — **no rounding in compute**; `nan` = honest refusal (engine emits
`invalid:<f>`); `params=None` or `candles=[]` → `ValueError`. Non-finite close
(`nan`/`inf`) or non-finite `high/low` where used → `nan`, never a number from junk.

Universal param validation (§3.13, mirrors `rsi_14._period`): numeric, `isfinite`
checked **before** `int()` (never `int(inf)` crash-class), integral, ≥ per-file bound;
else `ValueError` (spec-frozen — `# noqa: TRY004` where ruff requires).

## REV4 pin resolutions for this batch (binding — no silent forks)

- **ATR TR = TradingView `ta.tr(true)`**: `TR_0 = high_0 - low_0`, then
  `max(h-l, |h-prev_c|, |l-prev_c|)`. REV4 min-bars pin "15 conditional on TR policy"
  resolves to **`minimum_history=14`** (TV TR yields TR at bar 0 → seed needs 14 TRs =
  14 candles). Label: "TradingView ta.tr(true) compatibility".
- **Wilder smoothing** (ATR/ADX): first value = SMA of first n samples, recursive
  α = 1/n after — same pin as RSI.
- **No epsilon guards anywhere** — branch on exact zero (D2); degenerate cases are
  spec'd branches below, each a canonical project rule.
- **EMA inside MACD = Pine first-value seed** (m3.1 golden-locked pin, reused).
- **σ = population std, `ddof=0`** (REV4 BB pin) — used by `std_20`, `zscore_20`,
  `bb_percent`, `vol_regime`, `hurst`.
- Min-bars are mathematical minima except `macd minimum=26=slow` (chart-true gate,
  follows the §8b EMA exemplar precedent `EMA20: minimum 20`).

## Per-analytic definitions (REQUIREMENTS / params / math / canonical branches)

1. **`sma_20`** — `min=20, warmup=0, defaults={"period": 20.0}`, period integral ≥ 1.
   Mean of last `p` closes. `n < p` → `nan`.
2. **`std_20`** — `min=20, warmup=0, defaults={"period": 20.0}`, period integral ≥ 1.
   Population σ (`ddof=0`) of last `p` closes. Flat window → `0.0` exactly.
   `n < p` → `nan`.
3. **`zscore_20`** — `min=20, warmup=0, defaults={"period": 20.0}`, period integral ≥ 2.
   Window = last `p` closes; `z = (last - mean) / σ` (σ `ddof=0` same window).
   **Canonical: `σ == 0` → `0.0`** (flat window: last == mean, 0/0 has no dispersion
   meaning — baseline zero, never `nan`). `n < p` → `nan`.
4. **`returns`** — `min=2, warmup=0, defaults={}` (no params).
   Last log return `ln(close_n / close_{n-1})`. `n < 2` → `nan`;
   any of the two closes ≤ 0 → `nan` (log domain); non-finite → `nan`.
5. **`atr_14`** — `min=14, warmup=0, defaults={"period": 14.0}`, period integral ≥ 1.
   TV-style TR (pin above); seed `ATR = mean(TR_0..TR_{p-1})`, recursive Wilder after.
   `n < p` → `nan`. Non-finite high/low/close → `nan`. Range: `[0, +inf)` — flat → `0.0`.
6. **`adx_14`** — `min=28 (=2p, REV4 pin), warmup=0, defaults={"period": 14.0}`,
   period integral ≥ 1. For i ≥ 1: `+DM = h_i-h_{i-1}` if it beats `l_{i-1}-l_i` and
   is > 0 else 0; `−DM` symmetric; TR with prev close (standard). Wilder-smooth each
   over p (seed = mean of first p). `+DI = 100·s+DM/sTR`, `−DI` symmetric.
   **Canonical branches:** `sTR == 0` → both DI = `0.0`; `(+DI + −DI) == 0` →
   `DX = 0.0`; DX = `100·|+DI − −DI| / (+DI + −DI)`. ADX = Wilder smooth of DX over p
   (seed = mean of first p DX). `n < 2p` → `nan`. Flat series → `0.0` exactly.
7. **`macd`** — `min=26 (=slow, chart-true), warmup=0, defaults={"fast": 12.0,
   "slow": 26.0}`; both integral ≥ 1, **`fast < slow` else `ValueError`**.
   First-value-seeded EMAs (Pine pin): line = `EMA_fast - EMA_slow` (last values).
   `n < slow` → `nan` (EMA_slow not yet through one full period). Can be either sign.
8. **`bb_percent`** — `min=20, warmup=0, defaults={"period": 20.0, "stddev": 2.0}`;
   `period` integral ≥ 1, `stddev` finite ≥ 0.
   Window = last p closes; `%B = (last - lower) / (upper - lower)` with
   `upper/lower = mean ± k·σ` (σ `ddof=0`).
   **Canonical: width == 0 (σ == 0 or k == 0) → `0.5`** (price at midline).
   `n < p` → `nan`. Output unbounded (outside bands is legal, no clamp).
9. **`donchian_20`** — `min=21 (=p+1), warmup=0, defaults={"period": 20.0}`,
   period integral ≥ 1. Prior window = `candles[-(p+1):-1]` (**current bar excluded** —
   breakout semantics). `prior_high/prior_low` = max highs / min lows of that window;
   `last` = current close.
   `range > 0` → `100·(last - prior_low)/range` (may exceed 100 / go below 0 — that
   IS the breakout signal, no clamp). `range == 0` (collapsed window):
   **canonical** `100.0` if `last > prior_high`, `0.0` if `last < prior_low`, else
   `50.0` (no breakout). `n < p+1` → `nan`. Non-finite h/l/c → `nan`.
10. **`choppiness`** — `min=14, warmup=0, defaults={"period": 14.0}`, period
    integral **≥ 2** (`log10(p)` denominator — p=1 → `ValueError`, adversarial).
    Window = last p bars; TV-style TR within the window; `sumTR = ΣTR`,
    `range = max(highs) - min(lows)` of the window.
    `range == 0` → **canonical `100.0`** (flat channel = pure chop).
    `sumTR == 0 ∧ range > 0` (impossible under TV TR — still guarded) → `0.0`.
    Else `chop = 100·log10(sumTR/range)/log10(p)` — theoretical range `(−inf, 100]`,
    no clamp (honest; 100 bounded by `TR_i ≤ range` each). `n < p` → `nan`.
11. **`vol_regime`** — `min=40 (=2w), warmup=0, defaults={"window": 20.0}`, window
    integral ≥ 1. Disjoint windows: `σ_now` = pop-σ of `closes[-w:]`,
    `σ_hist` = pop-σ of `closes[-2w:-w]`.
    **Canonical: `σ_hist == 0` → `1.0`** (flat history cannot normalize — baseline
    neutral, even if σ_now > 0; documented, tested).
    Else ratio `σ_now / σ_hist` (unclamped — >1 = current window hotter).
    `n < 2w` → `nan`.
12. **`hurst`** — `min=51 (=w+1), warmup=0, defaults={"window": 50.0}`, window
    integral **≥ 2** (`ln(w)` denominator — w=1 → `ValueError`, adversarial).
    Log returns over last `w+1` closes → w returns (≤ 0 close → `nan`).
    `mean = Σr/w`; cumulative `X_0 = 0, X_k = X_{k-1} + (r_k - mean)`;
    `R = max(X_0..X_w) - min(X_0..X_w)`; `S` = pop-σ of the w returns.
    **Canonical: `S == 0` → `0.5`** (deterministic series has no measurable memory —
    neutral; single-branch: `S == 0 ⇔ R == 0` for centered steps).
    Else `H = ln(R/S)/ln(w)` — full precision, **no clamp** (pathological series may
    fall outside [0,1]; honest output, no fake bounds). `n < w+1` → `nan`.
