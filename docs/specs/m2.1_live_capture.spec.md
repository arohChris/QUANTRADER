# Spec: M2.1-live Capture — live Deriv ticks → lake parquet → read-back (G0 data-layer closer)

Purpose: One re-runnable script proves the FULL data path with REAL network data: capture N live
ticks from the **A41-signed endpoint** → production pipeline (M2b.2 lineage stamp + M2.2 normalize
+ M2.8 LakeWriter) → **real lake** `data/lake/` → LakeReader read-back asserted equal to the
capture. Closes BUILD_STATUS Known Bug *"data layer has never held real data"* — prerequisite for
G0 walk-forward on real data.

## Slice artifacts

- Script: `scripts/verify_m2.1_live_capture.py` — network + CLI + orchestration ONLY (composes
  existing production components exactly as `verify_m2.4_*` / `verify_m2.8_storage.py` do).
- Module: `modules/m2_market_data/capture.py` — pure helpers, THE tested unit (no sockets at import).
- Tests: `tests/m2_market_data/test_m2.1_live_capture_spec.py` — pytest NEVER opens a socket
  (network only in verify Step 7); fakes + fixtures only.
- Runtime outputs: `data/live_capture/<UTC-YYYY-MM-DD>/raw_<symbol>.jsonl` (+ `drops.jsonl`);
  parquet under `data/lake/` via the **frozen** partition formula (both dirs gitignored).

## Inputs (CLI)

- `--symbol` default `cryBTCUSD` (24/7 → verify runnable any day; `frxEURUSD` for forex once open).
  Validated non-empty/non-blank; passed to the feed opaque (M2.1 rule).
- `--ticks N` default 50, integer ≥ 1; `--timeout-s` default 60; `--connect-retries` default 8;
  `--lake-root` default `data/lake`; `--out-dir` default `data/live_capture`.
- **Endpoint config-driven:** `ws_url` + `app_id` read from `config/brokers/deriv.yaml` (A41 value
  `wss://api.derivws.com/trading/v1/options/ws/public`, `app_id=1089`) — never hardcoded in code.
- `app_id` goes **in the URL query only** (see KNOWN DEVIATION).

## capture.py contracts (tested unit)

- `build_capture_frame(symbol: str) -> str` — JSON with **exactly** keys `{"ticks", "subscribe"}`
  (int 1). No `app_id` in body.
- `validate_args(symbol: str, n_ticks: int) -> tuple[str, int]` — `ValueError` on blank symbol or
  `n_ticks < 1`; returns normalized pair.
- `classify(msg: dict) -> str` — `"tick"` | `"closed"` (error.code == `MarketIsClosed`) |
  `"error"` | `"other"`.
- `to_jsonl_line(obj) -> str` / `from_jsonl_line(line: str) -> dict` — lossless JSONL roundtrip
  (quote preserved as **string** — no float roundtrip); invalid line → `CaptureError`.
- `connect_with_retry(connect, *, attempts: int, sleep) -> Any` — retries only connection-phase
  failure; returns first success; exhausts → `CaptureError` naming attempts (flaky local DNS).
- `filter_run_rows(rows: list[dict], epochs: set[int]) -> list[dict]` — keep rows whose `epoch`
  is in this run (prior-run rows in same daily partition are excluded from asserts).
- `assert_readback(*, captured: list[dict], rows: list[dict], drops: list[dict], tick_size) -> ReadbackReport`
  — all checks raise `CaptureMismatchError(check, detail)` naming epoch/expected/actual:
  1. **reconcile:** `len(captured) == len(rows) + len(drops)`
  2. **price:** for each captured tick epoch: `Decimal(str(row["price"])) ==
     round_to_tick(Decimal(str(quote)), tick_size)` — compare via str→Decimal only, never float math
  3. **chronology:** row epochs non-decreasing (equal allowed — sub-second feeds share epochs)
  4. **lineage:** every row `reference_snapshot_id` non-empty str
  - success → `ReadbackReport(captured, accepted, dropped, first_price, last_price)` (dataclass).
- `round_to_tick(price, tick_size)` — re-export of M2.2 HALF_UP rule (single rounding source).

## Edges (1 test each)

- E1 connect fails (DNS flaky) → retry ≤ attempts then `CaptureError`; fake raising 2× then OK →
  succeeds with attempts counted.
- E2 `MarketIsClosed` → `classify == "closed"`; script exits 3 printing open-time from
  `code_args` (NO auto symbol-switch — deterministic runs).
- E3 zero ticks within timeout → script fails (exit 1) — an empty run NEVER passes.
- E4 malformed frame mid-stream → recorded in `drops`; reconcile must balance or mismatch raised.
- E5 lake partition already holds prior-run rows → `filter_run_rows` isolates this run before asserts.
- E6 any epoch price mismatch → `CaptureMismatchError` naming epoch + expected/actual.
- E7 non-decreasing epochs violated → `CaptureMismatchError`.
- E8 empty/missing `reference_snapshot_id` on any row → `CaptureMismatchError` (lineage mandatory).
- E9 `validate_args`: `n_ticks=0` → `ValueError`; `""`/`"   "` → `ValueError`.
- E10 frame guard: `build_capture_frame("cryBTCUSD")` json keys exactly `{"ticks","subscribe"}`.
- E11 JSONL roundtrip preserves quote string exactly (e.g. `"83668.324"`).
- Adversarial (not in spec): captured quote `"NaN"` / `"1e12"` → Decimal parse safe, mismatch path
  raises named error (never silently passes); symbol `'; DROP` → frame stays valid JSON, opaque.

## Correctness

- Round: **HALF_UP once** to tick_size (M2.2 `_round_to_tick`, Option B).
  Hand calc: quote `83668.324`, tick `0.01` → 8366832.4 → HALF_UP 8366832 → **83668.32**.
  Hand calc: quote `1.12345`, tick `0.00001` → identity **1.12345**.
- Lineage: `reference_snapshot_id` from M2b.2 `current_snapshot_id()` (`REF-YYYY-MM-DD-NNN`),
  stamped exactly once by M2.2 (normalize.py:96) — non-empty on every stored row.
- Prices: Decimal everywhere in asserts (`Decimal(str(x))`); no float equality.
- Script exit codes: 0 PASS / 1 verify-fail / 2 connect-or-args / 3 market-closed; prints
  captured/accepted/dropped counts + lake paths + first/last price.

## KNOWN DEVIATION (recorded, not silent)

Frozen `broker_feeds/deriv/stream.py:build_tick_subscribe` puts `app_id` **in the body** — the
new endpoint **rejects** that (`InputValidationFailed`, empirically proven 2026-09-25: body with
app_id → rejected; without → accepted). This slice uses script-local `build_capture_frame`.
Production M2.1 live wiring will need its own §5 amendment later (frozen tests assert body app_id)
— flagged in BUILD_STATUS Open Questions. **Nothing frozen is changed here.**
