## 1. Purpose

Expose the backend's frozen contracts to the frontend over a versioned, authenticated,
tenant-scoped HTTP and WebSocket surface, without letting the browser reach any store or
Python module directly.

## 2. Why this is a parent spec, not a leaf spec

`AGENTS.md` §2 Step 1 requires splitting a sub-module when its spec cannot be stated in a
few sentences. This one cannot. The bible allocates **eight** router modules to M10.2:

`api/v1/{router, market_data, analytics, portfolio, risk, orders, executions, health}.py`
`System_Development_Manual/modules/10_M10_Experience.md:52`

Writing one spec covering all of them would be a spec larger than the implementation and
vague about every part. So this document specifies only what is **genuinely shared and must
be frozen exactly once**, then enumerates the leaf specs. Each leaf gets its own spec, its
own tests, and its own human gate.

## 3. Inputs, outputs, invariants

### 3.1 Inputs (all server-derived — never client-supplied)

```text
Principal.user_id          str        # from validated JWT
Principal.role             str        # viewer | trader | admin
Principal.active_broker    str        # e.g. deriv
Principal.permissions      frozenset  # from frozen RBAC
X-Correlation-Id           UUID       # request id, echoed in meta
Idempotency-Key            UUID       # required on writes
```

### 3.2 Outputs

The §7.2 envelope, one JSON object per response, with a frozen `schema_version` per
contract. Money fields are `Decimal` serialized as JSON **strings**, never floats, at 2dp
quote-currency / 5dp price per `shared/core/money.py`. `AGENTS.md` §3.1

### 3.3 Invariants — a handler that violates any of these is wrong

1. **A handler never accepts identity.** `user_id`, `role`, or `tenant_scope` in a request
   body or query string is **rejected**, not ignored. Identity is injected server-side.
2. **A handler never computes business values.** No indicator, PnL, margin, or sizing.
3. **A handler never touches a store or another module's internals.** It calls a module
   **through a frozen contract**. `AGENTS.md` §5
4. **Every response carries `correlation_id`.** `AGENTS.md` §3.12
5. **Every error uses a frozen `ErrorCode`.** The enum is the only source; inventing a
   string in a handler is a defect. `financial_analyst_app/shared/contracts/errors.py:14`
6. **Every write is idempotent.** Same `Idempotency-Key` ⇒ same result, no second effect.
   `AGENTS.md` §3.2
7. **A handler is thin.** Validate → resolve principal → set tenant context → call module →
   wrap envelope. Target ≤30 lines, including imports. `10_M10_Experience.md:53`
8. **Unknown state fails safe.** Missing data, missing capability, or unresolvable identity
   yields the safe assumption, never a permissive default. `AGENTS.md` §3.3

## 4. Shared contract, frozen once (slice 1)

Applies to every endpoint. Detailed in `m10.2_envelope.spec.md`; summarized here so the
leaf specs can reference it rather than restate it.

```json
{ "data": {}, "meta": { "correlation_id": "…", "as_of": "…Z", "schema_version": "1.0" }, "error": null }
```

| Rule | Value |
|---|---|
| Success | `error: null`, `2xx` |
| Failure | `data: null`, `error.code` from the frozen enum, `4xx`/`5xx` |
| Auth failure | `401` (no/invalid token) or `403` (valid, insufficient) |
| Pagination | `?limit=` default 50, max 500, opaque `cursor`, `next_cursor` + `has_more` |
| Rate limit | `429` + `Retry-After`; client backs off with jitter |
| Deprecation | `Sunset` header; `patch`/`minor`/`major` per `schema_version` policy |

**Retired:** `BaseAppError.to_dict()` emits a third shape and must be aligned to the
envelope or removed. `financial_analyst_app/shared/core/exceptions.py:14-26`

## 5. Edge cases — required behaviour

| # | Case | Required behaviour |
|---|---|---|
| 1 | No `Authorization` header | `401`. Never a default role. |
| 2 | Invalid/expired token | `401`, no fallback to `X-Role` |
| 3 | `X-Role` sent **and** OIDC configured | `X-Role` **ignored entirely** |
| 4 | Valid token, insufficient permission | `403` with a frozen code |
| 5 | `role` in request body | `422` — identity is not client-settable |
| 6 | Unknown `instrument_id` | `404` with `unknown_symbol` |
| 7 | Unsupported `timeframe` | `422`; the registry is authoritative, not a free string |
| 8 | `limit` > 500 | `422`, not silently clamped |
| 9 | `cursor` malformed or expired | `400`; never a partial page |
| 10 | Collection empty | `200` + empty list + `has_more: false` — **never `404`** |
| 11 | Store unreachable | `503` + retryable code; **never** an empty-but-successful page |
| 12 | Candle gap present | `200` with `quality=gapped` and an explicit gap marker |
| 13 | Warmup incomplete | `200` with `WARMING_UP`; not an error, not silently final |
| 14 | Partial timeframe coverage | Partial rows + explicit coverage flag; never invented candles |
| 15 | Same `Idempotency-Key` replayed | Original response returned; no duplicate effect |
| 16 | Two tenants, same instrument | Market data identical (global, no `user_id`); private data isolated |
| 17 | `as_of` before any data | `200` + empty + reason, not a fabricated default |
| 18 | Malformed JSON body | `422`, typed, never a stack trace |
| 19 | Oversized payload | `413`; rejected before parsing |
| 20 | Broker disconnected | `503` on broker-backed reads; cached data served **with** a stale flag |

## 6. Definition of correct

- The envelope, error codes, pagination, and rate limiting match §4 exactly.
- Every response is traceable end-to-end by `correlation_id` alone.
- **A browser cannot name a store, a table, or a Python module** in any request.
- A second frontend generated from `openapi.json` needs no hand-written type to call the
  API correctly.
- A drifted contract **fails CI**, not production.
- No handler reaches into another module's internals; `lint-imports` proves it.

## 7. Adversarial cases — must fail safely with a typed code

These are deliberately **not** in §5 and exist to catch unsafe assumptions:

| Input | Must |
|---|---|
| `instrument_id = "../../etc/passwd"` | `422` — no filesystem access |
| `cursor` = 1 MB of garbage | `400` fast, no memory blowup |
| `limit = -1` | `422` |
| `as_of` = year 3000 | `422` or empty-with-reason; never silently "now" |
| `as_of` = naive datetime, no timezone | `422` — UTC is mandatory. `AGENTS.md` §3.8 |
| `Authorization: Bearer <alg=none>` | `401` — algorithm must be pinned |
| Token signed by a **different** issuer | `401` — audience/issuer verified |
| `X-Role: admin` with no token, OIDC off | Allowed **only** in an explicitly local config, and logged |
| Duplicate query params (`?limit=1&limit=9999`) | Rejected; never last-wins |
| 10,000-item collection, no `limit` | Server caps at 500; no unbounded read |

## 8. Out of scope

- Business analytics, indicator maths, sizing, risk arithmetic — all backend modules.
- Any M5/M6/M7 private surface (slice 8) until those modules exist.
- Account-gate behaviour changes. The process-global `AccountGateService` is an **M1.3**
  change proposal, not an M10.2 edit.
- Serving frontend static files. The backend never serves HTML. `AGENTS.md` §4.2
- Multi-tenant per-user tick topics. Market data is global. `AGENTS.md` §4.3

## 9. Build-order constraint (binding)

A65 places the API gateway **last**, step 9 of 9, and no step may be skipped. Steps 7
(strategy engine) and 8 (validator) are the current frontier. `BUILD_STATUS.md:89`

**This spec may be written, reviewed, and frozen now. No handler may be implemented until
A65 step 7 is complete.** Designing the contract early is required; building it early is
prohibited.

## 10. Test plan (written before implementation, per `AGENTS.md` §2 Step 3)

Per leaf slice, in `financial_analyst_app/tests/m10_2/test_m10.2_<part>_spec.py`:

- one test per §5 edge case, named after the case;
- the §7 adversarial cases, asserting a specific typed code — never "does not raise";
- a `correlation_id` round-trip test proving the id survives into logs;
- a tenant-isolation test proving two principals cannot read each other's private data;
- a no-reach test asserting the frontend bundle contains no `from modules` / `from shared`;
- money-path asserts as exact `Decimal` strings, never `pytest.approx`.

Plus, once, at the parent level:

- `openapi.json` snapshot test, failing on un-regenerated drift;
- an import-linter contract proving `modules/experience` reaches other modules only via
  frozen contracts.

## 11. Hand-verification

Not a money path, so no `Decimal` hand-calcs. Required instead: a **real-data** check —
`scripts/verify_m10.2_health.py` against a running app, and one candles response compared
against the same window read directly through the PIT service, asserting identical rows.
`AGENTS.md` §2 Step 7
