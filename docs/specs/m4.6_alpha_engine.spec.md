## Components — `loop.py` / `AlphaEngine`

Construction: `AlphaEngine(*, names: tuple[str, ...], runner: StrategyRunner,
sink: SignalSink)`. `names` = ordered strategy set (callers pass
`registry.names()`); duplicates or non-`str` → `ValueError` at construction
(config bug fails startup, §3.13). Engine is **stateless** across candles —
concurrent `on_candle` calls are safe without locks (no shared mutable state).

```python
async def on_candle(self, market: MarketData, *, env: Literal["prod","paper"],
                    now: datetime, user_id: str | None = None,
                    strategy_params: dict[str, float] | None = None
                    ) -> CandleOutcome
```

**Phase 0 — validate once, before ANY runner call (unconditional, even `names=()`):**
1. `market.kind == "candle"` else `ValueError`; `isinstance(market.payload, Candle)`
   else `ValueError` (contract pair is not structurally enforced — adversarial).
2. `market.instrument_id` non-empty str, `market.broker` non-empty str.
3. `now` and `payload.interval_end`/`interval_start` tz-aware UTC (same rule as
   runner `_require_utc`); `interval_end > interval_start` else `ValueError`.
4. **Formative refusal:** `payload.interval_end > now` → `ValueError` — THE
   no-look-ahead boundary at this layer (as_of may never be in the future).
5. `env` in {prod, paper} else `ValueError` (validated here, not only in runner:
   empty `names` must not let `env="live"` pass silently).
6. `asset_class` derived from `instrument_id` prefix: `FX.`→`forex`,
   `CRYPTO.`→`crypto`, `COMMODITY.`→`commodity`; unknown prefix → `ValueError`
   (deterministic, no config read).

**Phase 1 — quality gate (market state, not a bug → return, not raise):**
`payload.quality_status in {COMPLETE, LOW_ACTIVITY}` → run; anything else
(`GAP_AFFECTED`, unknown future values) → return
`CandleOutcome((), (), skip_reason=f"quality={payload.quality_status}")` with
**zero runner calls** (§3.3 gapped → skip signal; unknown → safer).

**Phase 2 — run (per name, given order):**
```python
for name in self._names:
    try:
        sig = await self._runner.run(name, market=market, instrument_id=...,
            broker=market.broker, timeframe=payload.interval,
            asset_class=..., as_of=payload.interval_end, now=now, env=env,
            user_id=user_id, strategy_params=strategy_params)
    except Exception as exc:          # isolation: ONE bad family never blocks
        failures.append(StrategyFailure(name, type(exc).__name__, str(exc)))
        continue                      # the other 6 (console precedent: ERROR row,
    if sig is not None:               # loop never crashes — m4.2 live signals)
        signals.append(sig)
```
`except Exception` only — `KeyboardInterrupt`/`SystemExit` propagate (tested).
Gated strategies (capability/lifecycle/evaluate-0.0) legitimately return `None`
from the runner — recorded as absent, NOT as a failure.

**Phase 3 — emit (after ALL runs, names order):**
`for sig in signals: await self._sink.emit(sig)` — sink errors **propagate**
(fail loud; partial-emit caveat documented: caller owns persistence/retry — Out).
Then return `CandleOutcome(tuple(signals), tuple(failures), None)`.

Logging: per candle `logger.debug` counts; per failure `logger.warning` with
strategy + error_type (correlation_id rides on each Signal) — §3.12 reconstructable.

## Correctness (definition of done)

- **Hand passthrough:** candle `interval_end = 2026-09-26T03:43:00+00:00`,
  `now = 2026-09-26T03:43:05+00:00` ⇒ every runner call received
  `as_of == 03:43:00` exact (PIT boundary = close time, never `now`),
  `timeframe == payload.interval == "1m"`, `now == 03:43:05` exact.
- **Asset-class hand:** `FX.EURUSD`⇒`forex`, `CRYPTO.BTCUSD`⇒`crypto`,
  `COMMODITY.XAUUSD`⇒`commodity` (runner receives exactly these literals).
- **Composition golden (real runner + real registries + scripted engine):**
  names `(trend_following, rsi_overbought_oversold, microstructure_flow)` with
  m4.1 hand values (ema_20=101, sma_20=100, rsi_14=65 / rsi_14=85) ⇒ outcome has
  `long strength 1.0` + `short strength 0.75` (hand comments reused from m4.1
  E12), microstructure absent via capability gate (0 engine requests for it —
  capability-before-I/O still holds through the loop), `failures == ()`.
- **Isolation:** scripted runner raises `ValueError("boom")` for name A ⇒ B and C
  still called, `failures == (A, "ValueError", "boom")`, B's signal present.
- **Determinism:** same inputs twice ⇒ equal outcomes modulo generated ids
  (m4.1 law carries — engine adds no randomness).
- No money anywhere (strength floats pass through untouched; hand-calc n/a).

## Edges (one test each; B-group adversarial)

- E1 happy path: COMPLETE candle, 3 names ⇒ runner called 3× in order, 2 signals,
  `failures ()`, `skip_reason None`.
- E2 formative: `interval_end > now` ⇒ `ValueError` (zero runner calls).
- E3 naive `now` / naive `interval_end` / naive `interval_start` ⇒ `ValueError`.
- E4 wrong shape (parametrize): `kind="tick"`; `kind="candle"` + `Tick` payload;
  `instrument_id=None`; `broker=""` ⇒ `ValueError` each, zero runner calls.
- E5 `GAP_AFFECTED` ⇒ zero runner calls, `skip_reason="quality=GAP_AFFECTED"`.
- E6 `LOW_ACTIVITY` ⇒ runs (runner called).
- E7 unknown `quality_status="WEIRD"` ⇒ skipped, `skip_reason="quality=WEIRD"`
  (unknown → safer, never runs).
- E8 isolation: raise for A ⇒ B/C still called, failure row exact, B's signal kept.
- E9 runner returns `None` for all ⇒ empty signals, `failures ()`, no raise.
- E10 asset-class derivation (parametrize 4): FX/CRYPTO/COMMODITY literals exact;
  `STOCK.AAPL` ⇒ `ValueError`.
- E11 passthrough hand: as_of/timeframe/now/user_id (None + "u1")/env exact on
  the recorded runner call kwargs.
- E12 emit: one `emit` per signal, signals order == names order; sink receives the
  same Signal objects (field equality).
- E13 sink raises `RuntimeError` ⇒ propagates out of `on_candle`.
- E14 `names=()` ⇒ empty outcome, sink never called — but invalid `env="live"`
  STILL raises (Phase 0 unconditional).
- E15 composition golden (Correctness above) through the REAL runner + real
  capability yaml + real strategy files.
- B1 `interval_end <= interval_start` ⇒ `ValueError`.
- B2 duplicate / non-str `names` at construction ⇒ `ValueError`.
- B3 runner raises `KeyboardInterrupt` ⇒ propagates (isolation catches
  `Exception`, not `BaseException`).
- B4 adversarial: hostile `strategy_params={"valid_until_seconds": -5}` with a
  REAL runner ⇒ runner's own `ValueError` lands in `failures` (isolated), other
  strategies unaffected.
