## Disjoint gap law (REV2 — the blocker that was fixed)

**`missing_watermarks` MAY be disjoint.**  
`to_intervals(missing)` → **list of contiguous inclusive runs** — **never** one global `(min,max)` that invents non-missing seqs.

```text
[5, 7]              → [(5,5), (7,7)]        # 6 NOT fetched
[5, 6, 10, 11, 12]  → [(5,6), (10,12)]      # 7,8,9 NOT fetched
[5, 6, 10, 11, 12, 20] → [(5,6), (10,12), (20,20)]  # §9 — three runs, chunk_count=3 if size large
[5, 7, 8]           → [(5,5), (7,8)]        # §9 — off-by-one / run boundary
[3, 4]              → [(3,4)]               # one run
[]                  → []
```

`on_gap` chunks **each run separately**, fetch/write only those runs.  
`missing_count = len(set(missing_watermarks))` — **unique ids requested**, consistent with runs (no inflated span).

**Write-fail contract (for M2.8):** if `fetch` ok and `write_backfill` raises, that chunk is **not** `chunks_done`; the watermark(s) remain **missing/recoverable**. Engine aborts remaining chunks (`partial` if some done else `failed`). Retries stay outside M2.7.

## Scope

**In (Day-1):**
- `GapAnalyzer.observe` + **`to_intervals` `@staticmethod`** (multi-run, pure)
- `ChunkOrchestrator.split` (per run)

- `financial_analyst_app/modules/m2_market_data/recovery.py`

**Out:** real REST/parquet · DB watermark · M2.5 source_sequence · retry/failover inside M2.7 · inventing seqs between disjoint runs · validating `instrument_id`/`broker` non-empty (MarketData contract guarantees; **do not invent** extra identity rules).

## Inputs

- **observe:** `instrument_id: str`, `broker: str`, `watermark: int` (`bool` rejected; `>= 1`)
- **on_gap:** non-empty `missing_watermarks: Sequence[int]` + injected `choose_source` / `fetch` / `write_backfill`
- **No clock.** Engine does not allocate watermarks.

## Outputs

1. **GapAnalyzer.observe** — cold start `[]` · contiguous `[]` · jump → `range(last+1, wm)` · `wm <= last` → `[]` hold last
2. **`to_intervals(missing)` → `list[(start,end)]`** **`@staticmethod` pure/stateless**; ascending, non-overlapping, covering **exactly** the unique missing values (contiguous runs only); empty → `[]`
3. **ChunkOrchestrator.split(interval)** → inclusive chunks; `chunk_size >= 1` else `ValueError`
4. **RecoveryEngine.on_gap → RecoveryResult** frozen: `status ok|partial|failed`, `missing_count` (unique), `chunk_count`, `chunks_done`, `source`, `detail` · empty missing → `ValueError` **before** choose/fetch/write · never mutates registry

## Correct

1. 1 then 2 → no gap.
2. 1 then 3 → missing `[2]`; `to_intervals` → `[(2,2)]`.
3. 1 then 5 → missing `[2,3,4]` → `[(2,4)]`.
4. Keys `deriv` / `mt5` independent.
5. `on_gap`: choose once; fetch+write once per chunk; ascending across runs then within run.
6. `chunk_size=2`, run `(2,4)` → `[(2,3),(4,4)]`.
7. Happy path ok, `chunks_done == chunk_count`.
8. Fail on 2nd chunk after 1st write → `partial`, `chunks_done=1`.
9. Fail on 1st chunk → `failed`, `chunks_done=0`.
10. Bad watermark type/`<1` → `ValueError`.
11. **Disjoint:** `missing=[5,7]` → intervals `[(5,5),(7,7)]` → fetch **only** those points (size 10 → two single chunks) — **6 never requested**.
12. **Disjoint multi:** `[5,6,10,11,12]` → `[(5,6),(10,12)]`.
13. `chunk_size=3`, run `(5,14)` → `[(5,7),(8,10),(11,13),(14,14)]`.
14. Fail on 3rd of 4 chunks → `partial`, `chunks_done=2`, 4th never attempted.
15. **Three-run disjoint (§9):** `[5,6,10,11,12,20]` → `[(5,6),(10,12),(20,20)]`; engine size 100 → `chunk_count=3`, covered exactly those six.
16. **Run boundary (§9):** `[5,7,8]` → `[(5,5),(7,8)]` — not `[(5,7),…]`, not `[(5,5),(7,7),(8,8)]`.
17. **Multi-interval chunking (§7):** missing `1,2,3,10,11,12,13,14` size 3 → fetch `[(1,3),(10,12),(13,14)]`, `choose_source` **once**.
18. **Size-2 multi-run fetch args:** `[5,6,10,11,12]` size 2 → fetch `[(5,6),(10,11),(12,12)]`.
19. **Disjoint 2+2 fetch args:** `[2,3,6,7]` size 2 → fetch `[(2,3),(6,7)]` — **4,5 never requested**.
20. **Dedup+sort:** `to_intervals([3,2,3,5])` → `[(2,3),(5,5)]`.

## Edges

- Cold start `1001` → `[]` (no invented 1..1000).
- Duplicate/stale → hold last.
- `to_intervals([])` → `[]`.
- `chunk_size > span` → one chunk per run.
- `on_gap([])` → `ValueError` before I/O.
- Write fail after fetch → chunk not counted; remaining aborted (see contract above).
- Duplicate `on_gap` same missing → both run (write-layer idempotency Day-2).

## Adversarial

- watermark `0` / `-1` / `True` / `False` / `"3"` / `1.0` → `ValueError`.
- `chunk_size=0` → `ValueError`.
- `choose_source` → `""` still used (no silent default).
- Huge contiguous 1..10_000, size 1000 → 10 chunks.
- **`missing=[5,7]` must not expand to include 6** (blocker test).
- **`[5,6,10,11,12,20]` → three runs only** (not one min–max span 5..20).
- **`[5,7,8]` → `[(5,5),(7,8)]`** (run-builder off-by-one).
