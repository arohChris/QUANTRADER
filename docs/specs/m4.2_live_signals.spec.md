# Spec: M4.2 Live Signals Console (`scripts/verify_m4.2_live_signals.py`)

Purpose: Human-directed (ACTION 57, 2026-09-26) live observation tool — open the Deriv
WebSocket, collect real data, and print M3 analytics + M4.2 strategy verdicts dry-run
(no orders, no Signal contract). Step-7-style live re-verification of the *complete*
m4.2 / m3.2 / m2.x chain via public APIs only. **No new calculations, no new modules.**

Inputs:
- Deriv `ticks_history` (style=candles, granularity=60, count N) → seed 1m candles
- Deriv `ticks` WS stream → live ticks (M2.1 capture frame + classify)
- `config/brokers/deriv.yaml` (ws_url + app_id — platform token, never printed)
- `config/capabilities.yaml`, `config/assets/*.yaml` (P18 profile params)
Outputs (stdout console + `data/live_signals/<date>/`):
- `history_1m.jsonl`, `live_ticks.jsonl`, `live_candles_1m.jsonl`, `drops_live.jsonl`,
  `evals_<runid>.jsonl` (machine-readable eval records for later true testing)
- every candle jsonl row (seed AND live) = `candle_row` output, exactly 7 fields —
  see helper 7 (amended 2026-09-26, ACTION 62: live rows were 4-field partials)

## Pure helpers (unit-tested, network-free — the only testable surface)

1. `history_candles_from_response(msg, *, timeframe="1m") -> list[Candle]`
   - `msg` not a dict (None/list/str) → `HistoryResponseError`
   - missing `candles` key, or not a list → `HistoryResponseError`
   - `candles == []` → `HistoryResponseError` (empty seed never passes, E3 mirror)
   - per-row invalid (epoch not int-non-bool, open/high/low/close non-numeric) → row
     skipped, valid rows kept; ALL rows invalid → `HistoryResponseError`
   - output sorted ascending by `interval_start`; `interval_start = epoch` (UTC aware),
     `interval_end = +60s` for 1m; `interval="1m"`; `tick_count = volume` if int-non-bool
     else 0; frozen `Candle`
2. `feature_union(modules) -> tuple[str, ...]` — dedup, first-seen order, over each
   `FEATURE_SLOTS[slot] = (analytic, overrides)`; module without `FEATURE_SLOTS` →
   `FeatureUnionError` naming the module; `()` for empty input
3. `slot_features(module, analytics) -> (mapped, missing)` — `slot ← analytics[analytic]`;
   absent or `None` value → `missing` entry `"slot=analytic"` (fail-safe, never raises);
   `analytics=None` → all slots missing; extra analytics keys ignored
4. `verdict(value) -> (direction, note)` — `0.0→("NONE", ...)`; `>0 → "LONG"`;
   `<0 → "SHORT"`; `|value| > 1` → note flags `out-of-range` (honest, never clamped)
5. `append_series(series, candle)` — replace-or-append by `interval_start` (amended
   2026-09-26 after live run: Deriv `end=latest` seed includes the FORMING candle;
   finalizing that same bucket live must REPLACE it, not duplicate the interval)
6. `reconnect_delay(attempt, rng, *, base=1.0, cap=30.0) -> float` (amended
   2026-09-26 after live crash — collector died after 8 min on
   `ConnectionClosedError: keepalive ping timeout`): exponential backoff with jitter,
   `min(cap, base * 2.0 ** min(attempt - 1, 60) * (0.5 + rng.random()))`
   - `attempt < 1` → `ValueError` (adversarial)
   - jittered value ∈ `[0.5, 1.5) ×` the exponential step, hard-capped at `cap`
   - huge `attempt` (e.g. `10**6`) → exactly `cap`, never OverflowError (adversarial:
     exponent clamped at 60 before `2.0 **`)
7. `candle_row(candle) -> dict` (amended 2026-09-26 after ACTION 62 — the live
   writer emitted only `interval_start/open/close/tick_count`, so every live bar
   was a partial that consumers (m4.6 reader) had to skip+count):
   - one serializer for ALL candle jsonl rows: seed `history_1m.jsonl`, live
     `live_candles_1m.jsonl` close events, and the trailing-final-flush row
   - always exactly 7 keys: `interval_start`/`interval_end` isoformat UTC-aware,
     `open/high/low/close` verbatim from the Candle, `tick_count` int
   - never mutates the Candle; output fully JSON-serializable (no datetime objects)

## Script behavior (edges + exit codes)

- seed fetch: `connect_with_retry` ≤8 attempts; API `error` frame → exit 2; market
  `closed` frame → exit 3 (prints opens time); 0 candles after parse → exit 1
- **seed retry ladder** (amended 2026-09-26, probed): on a closed market Deriv
  answers `end="latest"` with an EMPTY candle list — retry once with
  `end=now-86400` (returns last real bars); still empty → exit 1
- **live clock = `SystemClock`** (amended after probe: `SimulatedClock` frozen at
  startup made 99/100 live ticks drop `timestamp_ahead` "epoch ahead of clock")
- **reconnect on connection loss** (amended 2026-09-26 after live crash): `recv`/
  `send` raising `ConnectionClosed*`/`OSError` mid-stream → close socket, print
  `[reconnect] attempt=N reason=...`, sleep `reconnect_delay(N, rng)`, reconnect via
  `connect_with_retry` (≤8 tries), re-send the subscribe frame, resume with all state
  preserved (series, builder, counters, open jsonl files); one received message resets
  the attempt counter; >10 consecutive failures → exit 2 (bounded, never a silent
  reconnect storm); the `--duration-s` deadline is honored across reconnects
- live `connect` uses `ping_timeout=60` (websockets default 20s killed a healthy
  stream on one slow pong — observed 1011 close); reconnect makes any close survivable
- trailing partial bucket: `builder.close()` finalizes it INSIDE the evals-file
  scope — appended to the series and evaluated like any boundary candle
- seed eval runs **immediately** (as_of = max interval_end) so analysis+strategy output
  appears without waiting for a live boundary
- live loop: ingest → normalize → validate → CandleBuilder.on_tick; on finalized candle
  → one eval: `FeatureRequest(features=feature_union(eligible), as_of=closed.interval_end,
  timeframe="1m", asset_class="forex", param_overrides=<slot overrides merged per
  analytic>)`; engine capability-gates the feature set (P15)
- strategies evaluated only if `CapabilityRegistry.is_strategy_eligible(NAME, "deriv")`
  is `(True, _)` — ineligible (microstructure_flow) printed as `BLOCKED <reason>`, never
  evaluated (no order_book_imbalance on deriv)
- `evaluate` raising (missing slot / non-float) → row prints `ERROR <msg>`, loop never
  crashes; `value==0.0` printed as `NONE`
- every raw tick appended to `live_ticks.jsonl`; drops to `drops_live.jsonl`; each eval
  written to `evals_<runid>.jsonl`
- `--duration-s 0` (default) runs until interrupted; natural end requires ≥1 eval for
  exit 0; endpoint printed with query string stripped (no token in artifacts)
- Correctness anchor (composition golden): engine analytics → `slot_features(trend) →
  evaluate` must equal the m4.2 hand-calc: 101 vs 100, gap 1.0% ≥ full, rsi 65 ≥ 60 →
  `1.0` (asserted in tests via the helper chain; live run shows the same chain on real
  data).

Adversarial (tested): `msg=None`, `candles="junk"`, `epoch=True`, `close="abc"`,
`volume=3.7`, module without FEATURE_SLOTS, `analytics=None`, `verdict(1.5)`.
