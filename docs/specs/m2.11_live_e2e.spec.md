# Spec: m2.11 Live E2E Pipeline (Deriv → validate → 1m candles → HOT → WARM → read-back)

> **Queue:** m2.10 WARM ✅ (A45/A47) → **m2.11 (this slice)** → analysis/M4.1 remainder.
> **Gating:** closes the G0 data-layer end-to-end path across ALL built tiers in ONE
> re-runnable run: live WS → ingest → normalize → validate → candles → HOT (Valkey) →
> WARM (Timescale) → read-back reconcile. After this slice the data layer is provably
> wired; G0 exit itself still needs the walk-forward script (separate artifact).
> Naming: `docs/specs/m2.11_live_e2e.spec.md` / `tests/m2_market_data/test_m2.11_live_e2e_spec.py`
> / `scripts/verify_m2.11_live_e2e.py` (check_naming conform).

## 1. Purpose (one sentence)

Prove with a single re-runnable script that **live Deriv ticks traverse the entire
built data layer with zero silent loss** — every captured frame ends in exactly one
of: accepted+stored+read-back-verified, or a recorded typed `Drop` with reason.

**Inputs:** live Deriv WS frames (endpoint = `config/brokers/deriv.yaml` `ws_url` +
`app_id`, A41 signed — never hardcoded); infra: Valkey `127.0.0.1:6379` (M2.9),
Timescale `127.0.0.1:5432` + `QUANTRADER2/.env` DSN (M2.10, never printed).
**Outputs:** exit code + printed E2E report; artifacts under `data/live_e2e/<day>/`
(`raw_<symbol>.jsonl`, `drops_<symbol>.jsonl`, `e2e_report_<symbol>.json`); flushed
rows in `candles_1m`; HOT keys; lineage rows in the M2.8 lake (A42: lineage only).
**No money math** in this slice (n/a hand-calc).

## 3. Stages (the composition contract)

```text
S1 collect   raw frames        capture.build_capture_frame + connect_with_retry (sync WS)
S2 process   MarketData|Drop   TickIngestor.ingest → Normalizer.normalize → validate
S3 candles   Candle|None|Drop  CandleBuilder.on_tick per accepted md
                                (+ builder.close() at run end → finalize open bucket)
S4 hot       bool              HotStore.set_latest(md) per accepted md (M2.9 gate)
                                forming_key NOT written by this slice (A49-a: A33
                                invariant — finalized candles never stored in HOT;
                                CandleBuilder exposes no forming accessor, frozen
                                component untouched; forming proven separately by
                                verify_m2.9_hot.py 14/14 — printed either way)
S5 warm      FlushReport       finalized candles (boundary + close()) → flush_batch
                                (M2.10 FIFO + cursor; ON CONFLICT DO NOTHING)
S6 readback  assert            HOT get_latest == last accepted md (price + instrument)
                                WARM read_1m(window) ⊇ flushed set (A46 inclusive)
                                lake rows for run epochs (lineage; m2.1 pattern)
```

- S2/S3 are sync; S4-S6 are `async`; orchestrator `async def run_e2e(...)` composes
  them with **injected deps** (ws-collector fn, ingest/norm/validate — real classes,
  `HotStore`, `Candles1mStore`, `CandleBuilder`, `LakeWriter/Reader`) so tests run on
  fakes (FakeWS / in-memory hot / fake warm) — no network, no DB in unit tests.
- `process_frame(raw, ing, norm) -> MarketData | Drop` — one frame, three-stage,
  never raises on junk (malformed JSON → `Drop(reason=invalid_schema)`-equivalent via
  ingest, not an exception).
- Batching: `run_e2e` accepts `ticks: int` + `timeout_s`; flush happens ONCE at end
  (run-sized batch) — D2 4h-window flush semantics live in warm.py; this slice proves
  one flush cycle end-to-end, not the 4h timer (timer = ops runtime, out of scope).

## 4. Correctness — PASS (EXIT 0) requires ALL of C1–C7

- **C1 reconcile:** `captured == accepted + dropped` (epoch-filtered per run, the
  A44 `(tick.id, epoch)` dedup already applied inside ingest) — no frame unaccounted.
- **C2 accepted ≥ 1.**
- **C3 candles:** ≥ 1 candle flushed; WARM read-back **equals** flushed candles
  field-by-field (`interval_start/open/high/low/close/tick_count`) within the exact
  requested window (A46: verbatim args, inclusive, no auto-expand).
- **C4 HOT:** `get_latest(provider, instrument)` returns the last accepted md —
  price equal, `instrument_id` match; M2.9 watermark gate never regresses.
- **C5 drops recorded:** every drop has `reason` + `detail`; first 5 printed; artifact
  written even when 0 drops (empty file, honest).
- **C6 rerun idempotent:** second run same day/window → `inserted` may be 0..n
  (ON CONFLICT), read-back **superset** still passes; flush cursor never regresses;
  lake read-back filtered to run epochs (m2.1 `filter_run_rows`).
- **C7 no secret leakage:** every error string passes `warm.redact_dsn` (or is
  built from non-DSN parts) before print — password never reaches stdout/log.

## 5. Edges (each → one test named after it)

- **E1 empty capture** (0 ticks within timeout) → EXIT 1, never pass.
- **E2 market closed** (`MarketIsClosed`) → EXIT 3 + open-time printed (weekend forex).
- **E3 API/protocol error frame** → EXIT 2 + code/message (≤200 chars).
- **E4 all frames dropped by pipeline** → EXIT 1 + first-5 reasons + drops artifact.
- **E5 open bucket at run end** → `builder.close()` finalizes; with ≥1 accepted md
  there is **always** ≥1 candle (close() is the guarantee — E6 cannot co-exist with C2).
- **E6 builder refuses junk md** (missing/naive timestamp, non-positive price) →
  typed `Drop` lands in the drops list, run continues (propagated, not swallowed).
- **E7 Valkey down** → `ping()` False → EXIT 1 "HOT unavailable — verify requires
  live Valkey" (fail-loud; M2.9 runtime fail-open is product behavior — the verify
  script must NOT mask missing infra).
- **E8 Timescale down / DDL absent** → `apply_ddl` idempotent first; connect/flush
  failure → EXIT 1, message redacted (C7).
- **E9 rerun same day** → C6 (0..n inserted, superset passes, cursor monotonic).
- **E10 adversarial frame among live** (negative price / `ask` not numeric) →
  M2.3 drops it (m2.10 proved the door on sample rows), run continues, C5 records it;
  pipeline unit test injects junk directly (no live dependency).
- **E11 unsupported/foreign symbol frame** → normalized instrument lookup fails →
  typed `Drop`, not crash (fail-closed per M2.2/M2.3).
- **E12 latency** → per-stage ADVISORY timings printed (collect/process/hot/flush/
  readback), **never gated** (§4.1 budgets recorded for later enforcement).
