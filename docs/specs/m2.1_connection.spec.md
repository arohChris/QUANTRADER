## Inputs / Outputs

- **Config:** `config/brokers/deriv.yaml` gains `app_id: str` (platform app id — **not** a per-user vault token). `ws_url` already present. Env override `DERIV_APP_ID` if set.
- **Pre-WS validation (REV1):** `IngestionManager.start` **must** call `reference.exists(instrument_id, broker)` (or reject empty/unknown instrument list) **before** `get_or_create` — fail fast, **no WS opened for unknown instrument**. Unknown broker yaml → `ValueError` before connect.
- **API (async):**
  - `ConnectionManager.get_or_create(broker) -> ConnectionHandle` — singleton pool `{broker: handle}`; **never** keyed by `user_id`; guarded by **asyncio.Lock** (concurrent 100× still one WS).
  - `ConnectionManager.close(broker)` / `close_all()` — cancel heartbeat, close WS, drop from pool.
  - `IngestionManager.start(broker, symbols: list[str])` — validate symbols → connect → subscribe → recv loop + heartbeat tasks.
  - `IngestionManager.stop(broker)` — graceful stop, no orphan tasks.
- **Emit:** each `msg_type=tick` frame → existing `TickIngestor.ingest(raw, ...)` → `InternalTick | Drop` to injected `on_tick` / `on_drop`.
- **Status:** `ConnectionHandle.state ∈ {connecting, connected, degraded, reconnecting, closed}`; `consecutive_failures: int`; `last_heartbeat_at: datetime | None`.
- **Vault (explicit):** market-data path **must never call** `vault.get` / `broker_vault` — platform feed is public; asserted in tests.

## Connection behavior (Correct)

1. **Singleton + lock:** one WS per broker. Concurrent `get_or_create("deriv")` (N=100 tasks) → **exactly one** underlying connect, all callers same handle. Pool key is `str broker` only — **not** `(user_id, broker)`.
2. **Pre-WS validate:** unknown `instrument_id` (via `reference.exists`) → raise **before** any socket open; assert `connect` not called.
3. **Subscribe:** after open, send Deriv subscribe JSON per symbol (`{"ticks": "<native>", "subscribe": 1, "app_id": ...}`) — builder only in `broker_feeds/deriv/stream.py`.
4. **Heartbeat:** ping task every `heartbeat_interval_s` (default **20s**); no inbound (any msg_type) for `heartbeat_timeout_s` (default **35s**) → state `degraded` → force-close → reconnect. Protocol-level ping/pong counts as inbound.
5. **Reconnect:** full jitter `sleep = random(0, min(30, 1 * 2**attempt))` — **base 1s → cap 30s**, infinite while started; on success re-subscribe all symbols, reset `consecutive_failures`, state `connected`.
6. **Recv loop:** `async for frame in ws` → `msg_type=tick` → `TickIngestor.ingest`; `error` → log (no crash); `subscription` → log. Non-tick does **not** call ingest but **does** refresh heartbeat.
7. **Stop:** cancel recv + heartbeat; handle `CancelledError`; close WS; state `closed`; **idempotent** double-stop.
8. **Pure calc:** no `await` inside `ingest`.

## Edges

- Concurrent `get_or_create` ×100 → one WS (asyncio.Lock; second waiter gets same handle while `connecting`).
- Heartbeat timeout on silent-but-open socket → `degraded` → reconnect (false-degraded OK; safer than stuck).
- Server closes WS cleanly → recv ends → reconnect if still started.
- `start` twice → **no-op + log** (idempotent; no second loop).
- Unknown broker (no yaml) → `ValueError` before connect.
- Missing `app_id` → `ValueError` before connect.
- Unknown/empty `instrument_id` → `ValueError` (or equivalent typed reject) **before** `get_or_create` (REV1).
- `msg_type != "tick"` → no ingest call; still counts as inbound for heartbeat freshness.
- During `reconnecting`, `start` again → no second loop.
- `symbols=[]` → connect + heartbeat only, no subscribe frames (valid empty subscription).
- `vault.get` never on this path (any call → test fail).

## Adversarial

- Fake WS never sends → after timeout: `degraded` then `reconnecting` (not hung forever).
- Fake WS `ConnectionError` on recv → `consecutive_failures`++; backoff schedule advances; **capped at 30s**.
- Corrupt frame `"{{{"` → `Drop(invalid_json)` once from existing ingest; connection stays `connected`.
- Hostile frame payload: `None` / `[]` / `""` / 10_000-char string / `"; DROP TABLE` / embedded `\0` → connection layer does not crash; handed to ingest → typed Drop or accepted opaque symbol (never execute/interpolate).
- `tick.symbol = "'; DROP TABLE"` → opaque string at connection+ingest; no SQL/path use (M2.2/M2b gate later).
- Task leak: after `stop()`, no live asyncio tasks for manager.
- **No vault:** monkeypatch `vault.get` to raise → full happy path still works (proves never called).
